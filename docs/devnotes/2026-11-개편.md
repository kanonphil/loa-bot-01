## 접속과 안정성

- 봇 데이터는 매일 새벽 자동으로 백업되고, 다른 서버에도 사본이 하나 더 보관됩니다.
- 사이트는 이제 정해진 주소(dmlj-loa.online)로만 접속됩니다. 서버 IP로 직접 접속하는 길은 막았습니다.
- 업데이트는 테스트를 통과한 경우에만 자동으로 반영되고, 문제가 생기면 이전 버전으로 바로 돌아갑니다.

## 알림

- [배포 전] 알림 종을 열었을 때 방금 온 알림이 "읽음" 쪽에 섞여 보이던 문제를 고쳤습니다. 새 알림은 처음 열 때 새 알림으로 보입니다.
- [배포 전] 알림 설정에서 "모든 난이도"를 여러 번 추가하면 같은 항목이 여러 줄 생기던 문제를 고쳤습니다.
- [배포 전] 웹 서버가 재시작되는 사이에 온 초대·강퇴·일정 변경 알림이 웹 알림함에 안 들어오던 문제를 고쳤습니다.

- [배포 전] 다른 공대에 댓글이 달릴 때마다 보고 있던 화면이 통째로 새로고침되던 것을 줄였습니다. 관련 있는 변경일 때만 갱신됩니다.

- [배포 전] 봇이 재시작된 뒤에도 DM으로 받은 초대의 수락·거절 버튼이 그대로 동작합니다.
