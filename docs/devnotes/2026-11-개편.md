- [배포 전] 체크한 직후 아래에 뜨는 알림에서 "되돌리기"를 누르면 이전 상태로 돌아갑니다.
- [배포 전] 익스트림 레이드는 숙제표 아래 한 줄에서 체크하고 해제합니다.
- [배포 전] 받은 초대와 일정이 지난 내 공대를 홈의 "할 일"에서 바로 처리할 수 있습니다.
- [배포 전] 내 일정, 들어갈 만한 공대를 홈에서 볼 수 있습니다.
- [배포 전] 오늘의 콘텐츠(모험섬·필드보스·카오스게이트), 진행 중 이벤트, 점검 안내가 홈에 표시됩니다.
- [배포 전] 골드섬이 열리는 날, 시작 10분 전에 디스코드 DM으로 알려주는 알림을 켤 수 있습니다.
- [배포 전] 이번 주에 받은 골드와 남은 골드를 캐릭터별로 보여줍니다.
- [배포 전] "레이드 체크"와 "내게 온 초대" 화면은 홈으로 합쳐졌습니다. 예전 주소로 들어와도 홈으로 이동합니다.

## 원정대와 더보기

- [배포 전] 원정대의 캐릭터 카드에 전투력과 최근 7일 변화(▲/▼)가 표시됩니다.
- [배포 전] 캐릭터 추가나 부계정 추가에 실패하면 입력칸 바로 아래에 이유가 나옵니다.
- [배포 전] 전체 동기화가 오래 걸리면 실패로 끝나는 대신 "뒤에서 계속 진행 중"이라고 알려줍니다.
- [배포 전] 랭킹이 표로 바뀌었고, 전투력 랭킹에 "7일 성장" 열이 생겼습니다. 눌러서 성장 순으로 정렬할 수 있습니다.
- [배포 전] 캐릭터 상세에 최근 90일 전투력 기록 그래프가 추가됐습니다.
- [배포 전] 알림 설정이 웹 알림과 디스코드 DM으로 나뉘어 정리됐고, 켜고 끄는 항목은 스위치로 바뀌었습니다.
- [배포 전] 경매 분배금 계산기에서 시세가 있는 아이템은 "시세에서 가져오기"로 가격이 자동으로 채워집니다.
- [배포 전] 이용 가이드를 새 메뉴 구성에 맞게 다시 썼습니다.

## 메뉴와 화면 전체

- [배포 전] 왼쪽 메뉴를 홈 · 공대 · 원정대 · 더보기 네 개로 줄였습니다. 달력과 내 이력은 공대 안에, 랭킹은 원정대 안에 탭으로 들어갔습니다.
- [배포 전] 왼쪽 메뉴를 아이콘만 남기고 접을 수 있습니다. 접은 상태는 다음에 들어와도 유지됩니다.
- [배포 전] 알림 종을 누르면 그 자리에서 알림 목록이 열립니다. 전체·안 읽음으로 나눠 보고, 오늘·이번 주로 묶여 있습니다.
- [배포 전] 휴대폰에서는 아래쪽 탭 네 개로 이동하고, 알림 종은 위쪽에 있습니다.
- [배포 전] 삭제·취소처럼 되돌리기 어려운 동작은 무엇이 바뀌는지 적힌 확인 창이 뜹니다.
- [배포 전] 키보드로도 메뉴·알림·확인 창을 모두 쓸 수 있고, 어디에 있는지 테두리로 표시됩니다.
- [배포 전] 처리 중인 버튼에는 회전 표시가 나오고, 같은 버튼을 두 번 누르지 않게 막습니다.

## 접속과 안정성

- 봇 데이터는 매일 새벽 자동으로 백업되고, 다른 서버에도 사본이 하나 더 보관됩니다.
- 사이트는 이제 정해진 주소(dmlj-loa.online)로만 접속됩니다. 서버 IP로 직접 접속하는 길은 막았습니다.
- 업데이트는 테스트를 통과한 경우에만 자동으로 반영되고, 문제가 생기면 이전 버전으로 바로 돌아갑니다.

## 알림

- [배포 전] 알림 종을 열었을 때 방금 온 알림이 "읽음" 쪽에 섞여 보이던 문제를 고쳤습니다. 새 알림은 처음 열 때 새 알림으로 보입니다.
- [배포 전] 알림 설정에서 "모든 난이도"를 여러 번 추가하면 같은 항목이 여러 줄 생기던 문제를 고쳤습니다.
- [배포 전] 웹 서버가 재시작되는 사이에 온 초대·강퇴·일정 변경 알림이 웹 알림함에 안 들어오던 문제를 고쳤습니다.

## 공대

- [배포 전] 공대 상세에서 일정이나 메모를 고치는 중에 다른 사람이 공대를 바꾸면 입력하던 내용이 사라지던 문제를 고쳤습니다. 이제 화면 위에 "바뀐 내용이 있습니다" 안내가 뜨고, 원할 때 "지금 반영"을 누르면 됩니다.
- [배포 전] 다른 공대에 댓글이 달릴 때마다 보고 있던 화면이 통째로 새로고침되던 것을 줄였습니다. 관련 있는 변경일 때만 갱신됩니다.
- [배포 전] 댓글 시간이 9시간 늦게 표시되던 문제를 고쳤습니다. "13분 전"처럼 표시되고, 마우스를 올리면 정확한 시각이 보입니다.
- [배포 전] 공대 상세, 원정대, 알림 설정 화면이 조금 더 빨리 열립니다.

- [배포 전] 일정이 지났는데 아무도 처리하지 않은 공대는 "기한 만료"로 따로 표시됩니다. 예전처럼 클리어 기록에 섞이지 않고, 다음 주간 초기화 때 정리됩니다.
- [배포 전] 공대 일정이 6시간 넘게 지났는데 처리되지 않았으면 파티장에게 클리어나 취소를 해달라는 DM이 한 번 갑니다.
- [배포 전] 모집 마감한 공대에서 받은 초대도 이제 수락할 수 있습니다.
- [배포 전] 봇이 재시작된 뒤에도 DM으로 받은 초대의 수락·거절 버튼이 그대로 동작합니다.
- [배포 전] 공대 개설 버튼을 빠르게 두 번 눌러도 공대가 하나만 만들어집니다. 개설 응답도 빨라졌습니다(구독자 DM은 뒤에서 보냅니다).
- [배포 전] 일정이나 난이도를 짧은 시간에 여러 번 바꿔도 바로 반영됩니다. 디스코드 스레드 제목만 조금 늦게 바뀔 수 있습니다.
- [배포 전] 서포터 두 명이 동시에 참여를 눌러 한 파티에 서포터가 둘 들어가던 문제를 막았습니다.
- [배포 전] 익스트림 레이드의 "원정대 주 1회" 규칙을 참여·초대·게스트 모두 같은 기준으로 맞췄습니다.

## 레이드 체크와 원정대

- [배포 전] 공대 클리어로 자동 체크될 때, 같은 레이드를 다른 난이도로 직접 체크해 둔 기록이 남아 두 번 집계되던 문제를 고쳤습니다.
- [배포 전] 디스코드 /레이드체크에서 한 카테고리에 레이드가 많으면 오류가 나던 문제를 고쳤습니다.
- [배포 전] 캐릭터가 25개를 넘어도 디스코드 선택 메뉴에서 "더 보기"로 전부 고를 수 있습니다.
- [배포 전] API 키를 지웠다가 다시 등록하면 기존 캐릭터가 매일 자동 동기화에서 빠지던 문제를 고쳤습니다.
- [배포 전] 같은 API 키를 두 번 등록하지 못하게 했습니다.
- [배포 전] 로스트아크 서버 응답이 느릴 때 명령이 멈춘 채 끝나지 않던 문제를 고쳤습니다. 이제 잠시 후 다시 시도하라는 안내가 나옵니다.
