이용 가이드

디스코드 /가이드와 같은 내용을 웹 기준으로 정리했습니다. 처음이라면 위에서부터 순서대로 따라오면 됩니다.

  1. 1

    API 키 발급 · 등록

    로스트아크 개발자 사이트에서 로그인 → 내 정보 → API Key 관리 → 생성하기로 키를 발급받습니다.

    브라우저 자동 번역을 꼭 끄세요. 번역이 켜져 있으면 키가 한글로 바뀌어 등록에 실패합니다. 주소창 옆 번역 아이콘 → 영어 원문 표시 후 새로고침.

    디스코드에서 /api등록에 발급받은 키와 본인 캐릭터 이름 하나를 넣으면 등록이 끝나고, 그때부터 이 웹에 디스코드 계정으로 로그인할 수 있습니다.

    {% if not user %}디스코드로 로그인{% endif %}
  2. 2

    원정대 캐릭터 정리

    원정대 관리에서 등록된 캐릭터와 아이템 레벨을 확인합니다. 빠진 캐릭터는 이름으로 추가하고, 다른 로스트아크 계정이 있으면 부계정 추가에 그 계정의 API 키를 넣으면 원정대가 통째로 들어옵니다.

    아이템 레벨은 매일 04시에 자동으로 갱신되고, 전체 동기화를 누르면 바로 갱신됩니다. 공대 참여 때 여기 등록된 캐릭터 중에서 고르게 됩니다.

    디스코드: /원정대 /캐릭터등록 /캐릭터삭제

  3. 3

    공대 모집하기

    공대 개설에서 레이드 → 난이도 → 숙련도(숙련/반숙/트라이) → 일정 → 메모 순으로 고르면 디스코드 공대 포럼에 모집글이 자동으로 올라갑니다.

    개설한 뒤에는 공대 상세 페이지의 파티장 관리에서 초대·강제 퇴장·파티장 위임·일정 변경·난이도 변경을 할 수 있고, API를 등록하지 않은 서버 멤버도 게스트 초대로 부를 수 있습니다.

    디스코드: /공대모집, 게시물의 [관리] 버튼

  4. 4

    공대 참여하기

    공대 모집 목록에서 입장 가능 필터로 내 캐릭터 레벨에 맞고 자리가 남은 공대만 볼 수 있습니다. 공대를 열고 캐릭터와 역할(딜러/서포터)을 고르면 참여 완료.

    자리가 없으면 빈자리 알림을 켜두세요. 누가 나가면 알려줍니다. 파티장이 특정 슬롯으로 초대하면 내게 온 초대에서 수락하거나 거절할 수 있습니다.

    디스코드: /공대확인 /내공대, 스레드의 [참여하기] 버튼

  5. 5

    알림 설정

    알림 설정에서 세 가지를 따로 정할 수 있습니다.

    • 웹 알림 — 공대 모집 시작·클리어·게스트 합류 소식이 화면 토스트와 종 아이콘에 쌓입니다. 레이드 필터로 관심 레이드만 골라 받을 수 있어요.
    • 디스코드 DM 구독 — 구독한 레이드의 새 공대가 열리면 디스코드 DM으로 알려줍니다. (/레이드구독과 같은 설정)
    • 사전 알림 — 참여 중인 공대 시작 N시간 전에 미리 알려줍니다.

    초대·강제 퇴장·일정 변경처럼 나한테 온 소식은 구독과 상관없이 종 아이콘에 남습니다.

  6. 6

    주간 레이드 체크

    레이드 체크에서 캐릭터별로 이번 주 클리어를 누르고 해제할 수 있습니다. 공대가 클리어 처리되면 자동으로 체크되고, 캐릭터마다 레이드 선택으로 카드에 보일 레이드를 고를 수 있어요.

    매주 수요일 06:00에 초기화되며, 지난 주차 기록은 주차별 클리어 기록에서 볼 수 있습니다.

    디스코드: /레이드체크
