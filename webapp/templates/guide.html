이용 가이드

{% endif %}

디스코드 /가이드와 같은 내용을 웹 기준으로 정리했습니다. 처음이라면 위에서부터 순서대로 따라오면 됩니다.

  1. 1

    API 키 발급 · 등록

    로스트아크 개발자 사이트에서 로그인 → 내 정보 → API Key 관리 → 생성하기로 키를 발급받습니다.

    브라우저 자동 번역을 꼭 끄세요. 번역이 켜져 있으면 키가 한글로 바뀌어 등록에 실패합니다. 주소창 옆 번역 아이콘 → 영어 원문 표시 후 새로고침.

    디스코드에서 /api등록에 발급받은 키와 본인 캐릭터 이름 하나를 넣으면 등록이 끝나고, 그때부터 이 웹에 디스코드 계정으로 로그인할 수 있습니다.

    {% if not user %}디스코드로 로그인{% endif %}
  2. 2

    화면 구성

    왼쪽 메뉴(모바일은 아래 탭)는 네 칸입니다.

    • 홈 — 로그인하면 바로 이번 주 숙제표가 보입니다. 할 일(초대 · 일정이 지난 공대)과 내 일정도 여기 있습니다.
    • 공대 — 모집 중인 공대 목록, 달력, 내 공대 이력. 위쪽 탭으로 바꿉니다.
    • 원정대 — 내 캐릭터와 계정, 원정대 랭킹.
    • 더보기 — 알림 설정, 경매 분배금 계산기, 이 가이드. 관리자는 관리 화면도 여기서 들어갑니다.

    화면 제목 줄 오른쪽 끝의 알림 종을 누르면 새 알림과 지난 알림을 볼 수 있습니다. 모바일은 맨 위 줄에 있습니다.

  3. 3

    원정대 캐릭터 정리

    원정대의 내 캐릭터 탭에서 등록된 캐릭터의 아이템 레벨 · 전투력 · 마지막 동기화 시각을 확인합니다. 빠진 캐릭터는 이름으로 추가하고, 다른 로스트아크 계정이 있으면 부계정 추가에 그 계정의 API 키를 넣으면 원정대가 통째로 들어옵니다.

    아이템 레벨과 전투력은 매일 04시에 자동으로 갱신되고, 전체 동기화를 누르면 바로 갱신됩니다. 캐릭터가 많아 오래 걸리면 뒤에서 계속 진행되니, 잠시 뒤 새로고침하면 됩니다.

    랭킹 탭에서는 길드 전체의 전투력 · 아이템 레벨 · 주간 클리어 순위와 최근 7일 전투력 성장을 볼 수 있습니다. 캐릭터 이름을 누르면 상세 정보와 90일 전투력 기록 그래프가 나옵니다.

    디스코드: /원정대 /캐릭터등록 /캐릭터삭제

  4. 4

    이번 주 숙제 체크

    홈의 숙제표는 캐릭터가 행, 레이드가 열입니다. 난이도 버튼을 누르면 클리어로 체크되고 다시 누르면 취소됩니다. 공대가 클리어 처리되면 자동으로 체크됩니다.

    레이드 고르기로 표에 보일 레이드를 정하고, 지난 주 기록에서 이전 주차 클리어를 볼 수 있습니다. 익스트림 레이드는 원정대 단위로 주 1회만 체크됩니다. 매주 수요일 06:00에 초기화됩니다.

    할 일 상자에는 나에게 온 공대 초대(수락 · 캐릭터 바꾸기 · 거절)와 일정이 지난 공대(클리어 처리 · 취소)가 모입니다.

    디스코드: /레이드체크

  5. 5

    공대 열기

    공대 목록 위의 공대 열기 버튼을 누르면 한 화면에서 세 단계로 고릅니다. 오른쪽 미리보기에 디스코드 공대 포럼에 올라갈 모습이 그대로 보이고, 열면 모집글이 자동으로 올라갑니다.

    • 레이드 — 레이드와 난이도를 고릅니다. 최근에 연 공대를 누르면 일정과 조건까지 한 번에 채워집니다.
    • 일정 — 자주 쓰는 시간 칩을 누르거나 직접 고릅니다. 같은 시간대에 같은 공대가 이미 있으면 알려 줍니다.
    • 내 캐릭터 · 조건 — 입장 가능하고 이번 주 아직 안 간 캐릭터가 먼저 나옵니다. 숙련도(트라이/반숙/숙련)와 메모를 정합니다.

    연 뒤에는 공대 상세 페이지의 파티장 관리에서 초대 · 강제 퇴장 · 파티장 위임 · 일정 변경 · 난이도 변경을 할 수 있고, API를 등록하지 않은 서버 멤버도 게스트 초대로 부를 수 있습니다.

    디스코드: /공대모집, 게시물의 [관리] 버튼

  6. 6

    공대 참여하기

    공대 목록에서 입장 가능 필터로 내 캐릭터 레벨에 맞고 자리가 남은 공대만 볼 수 있습니다. 공대를 열고 캐릭터와 역할(딜러/서포터)을 고르면 참여 완료.

    자리가 없으면 빈자리 알림을 켜두세요. 누가 나가면 알려줍니다. 파티장이 특정 슬롯으로 초대하면 홈의 할 일 상자에서 수락하거나 거절할 수 있습니다.

    디스코드: /공대확인 /내공대, 스레드의 [참여하기] 버튼

  7. 7

    알림 설정

    알림 설정(더보기 → 알림 설정, 또는 왼쪽 아래 프로필 메뉴)에서 따로 정할 수 있습니다.

    • 웹 알림 — 공대 모집 시작 · 클리어 · 게스트 합류 소식이 화면 토스트와 종 아이콘에 쌓입니다. 알림 이력 구독, 받을 종류, 레이드 필터를 정할 수 있습니다.
    • 디스코드 DM 레이드 구독 — 구독한 레이드의 새 공대가 열리면 디스코드 DM으로 알려줍니다. (/레이드구독과 같은 설정)
    • 사전 알림 — 참여 중인 공대 시작 N시간 전에 미리 알려줍니다.
    • 골드섬 알림 — 켜 두면 그날 첫 골드 모험섬이 시작되기 10분 전에 디스코드 DM이 옵니다.

    초대 · 강제 퇴장 · 일정 변경처럼 나한테 온 소식은 구독과 상관없이 종 아이콘에 남습니다.

  8. 8

    경매 분배금 계산기

    더보기 → 경매 분배금 계산기에 템 가격과 인원을 넣으면 직접 쓸 때의 입찰 적정가와 되팔 때의 손익분기점이 나옵니다. 관리자가 시세 추적 아이템을 정해 두었다면 시세에서 가져오기로 가격 칸을 바로 채울 수 있습니다.
